# 阶段 1 真机验收清单

前置：一台已配对 Apple Watch 的 iPhone（iOS 26+，watchOS 26+）；开发者账号。

0. 把 `Config/Local.xcconfig` 里的 `SETMIO_TEAM_ID` 改成自己的 Team ID，`make generate`，用 Xcode 选 `Setmio` scheme 运行到 iPhone（手表 App 会随之安装；首次需在手表上信任）。
   记录：HealthKit / Live Activity / App Groups 能力是否由 Xcode 自动签名成功。

## M2 · HealthKit
1. 全新安装并启动 → 引导页：填档案 → 「连接健康」页点「授权访问『健康』」。系统授权表**只应列出**：读取（体重、体脂、瘦体重、心率、静息心率、HRV、呼吸率、腕温、步数、活动/基础能量、睡眠、训练、强度）与写入（训练、心率、活动能量、训练强度）。
2. 在授权表里先全部「不允许」→ 进入 App → 设置页点「请求授权」→ 到「健康」App → 共享 → App → Setmio 打开 → 回到 Setmio 下拉刷新：数据出现。
3. 设置页「重新导入健康数据」：导入期间显示进度条（逐类型），UI 不卡；记下完成后「今日」页行数/指标，再点一次「重新导入」，数值应不变（hkUUID 去重）。
4. 「今日」页：积累 ≥14 天夜间 HRV 基线后出准备度；不足时显示「数据不足 (n/14 天)」。（想先体验：设置 → 使用演示数据。）
5. 锁屏后台投递：锁屏状态下，在「健康」App 手动添加一条 HRV（或等次日早晨），解锁后打开 Setmio「今日」，评分/指标应已更新（无需手动点同步）。

## M3 · 计划闭环
6. 引导页选模板（推拉腿或上下肢）→ 「今日」出现今日计划，每个动作有决策理由；首次训练动作无目标重量。
7. 「训练」页「开始手机记录」→ 记几组（表单会按计划预填）→ 结束训练、评强度 → 「健身」App 出现来自 Setmio 的「传统力量训练」。
8. 次日（或把系统日期调到次日）「今日」：同动作的目标按双重渐进变化（顶端次数 → 加重；区间内 → 多 1 次）。准备度低时只改当天显示的副本（有橙色提示），第二天计划不受影响。

## M4 · Apple Watch
9. 手表打开 Setmio → 「开始计划训练」→ iPhone 上的 Setmio 进入镜像状态（无需手动打开；锁屏时 Live Activity 在记第一组后出现）。
10. 手表点「完成」记组：几秒内手机「训练」页/历史可见；休息计时归零时手表震动。分别测试：App 在前台；放下手腕/息屏（记录是否仍震动）；若息屏不震，应收到「休息结束」本地通知。
11. 结束并评分 effort=7 → 「健身」App：来自 Setmio 的「传统力量训练」，强度 7，时长正确；手机端该会话 `hkWorkoutUUID` 非空（训练页历史显示）。
12. 飞行模式：手机开飞行模式（或关蓝牙+Wi‑Fi）后在手表训练若干组 → 恢复连接 → 组出现在手机，**无重复**。
13. 训练中强杀手表 App（在手表上上滑关闭）→ 重新打开 → 训练恢复，已记组仍在，继续记组、结束后组数完整。

## M5 · Live Activity
14. 休息中在锁屏/灵动岛看到倒计时、下一组目标；点「暂停」→ 手表计时同步暂停、锁屏显示已暂停；点「继续」恢复；「+30s」「跳过」同样回传手表。
15. 手表上自己暂停/跳过 → 手机 Live Activity 随之变化。
